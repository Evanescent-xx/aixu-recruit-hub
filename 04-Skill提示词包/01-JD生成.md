# Skill 01 — JD 生成

## 触发词
`/jd`

## 输入格式
```
/jd [岗位Title] [职级P?] [用人经理一句话需求...]
```

例：`/jd 光伏组件研发总监 P7 上海 主导 N 型电池组件研发，希望电池或半导体背景、有 50 人团队管理经验`

## 步骤要点

1. **先拆需求**：从一句话中识别 5 个核心变量（岗位、职级、工作地、汇报线、关键场景）
2. **匹配模板**：在「01-知识库/岗位画像/」选最近模板，复用 60% 结构
3. **差异化填充**：
   - "你将负责" 5-7 条，按 MECE 拆场景
   - "我们希望你" 拆硬技能（红线）+ 软技能（加分项）
4. **自检**：
   - 是否含空话（"领导好"/"氛围棒"）→ 删除
   - 是否含歧视倾向词 → 替换
   - 薪酬带宽是否缺失 → 补"面议"或具体 Band
5. **附加动作**：自动生成 3 条社招渠道推荐 + 1 条目标公司清单

## 输出模板

```markdown
# [岗位 Title]
**[工作地] | [职级] | 汇报对象：[XX]**

## 一句话价值
> 这是一段不超过 30 字的钩子，决定候选人是否点开。

## 你将负责
- ...

## 我们希望你
**硬性**
- ...

**加分**
- ...

## 薪酬福利
- 现金：[Band]
- 长期激励：股权/项目奖
- 其他：补充医疗/落户/子女教育（按地域）

## 投递
- 联系人：XXX
- 内推奖金：XXX 元
```

## 反例（不要这么写）
- "积极主动、有责任心、沟通能力强" → 空话
- "年轻有活力" → 歧视倾向
- "能够承受较大工作压力" → 不写"较大"，直接说"高强度节奏"
