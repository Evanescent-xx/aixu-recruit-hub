# Skill 05 — 周报生成

## 触发词
`/weekly`

## 输入格式
```
/weekly
- 本周 JD 变化：新增 X / 关闭 Y
- 简历：初筛 X / 推荐 X / 面试 X / Offer X
- 亮点：...
- 卡点：...
- 下周计划：...
```

## 步骤

1. 数据校验：与招聘系统对账（口径不一致时以系统为准）
2. 看板生成：4 项核心指标 + 环比
3. 亮点 + 卡点：各 ≤ 3 条
4. 风险标红：薪酬带宽被压、关键岗位超时、流程卡点

## 输出模板

```markdown
# 招聘周报 — W40 (2026-09-28 ~ 2026-10-04)

## 一句话本周
完成 7 个 Offer 发放；N 型组件研发总监已终面待发 Offer；校招渠道启动。

## 数据看板
| 指标 | 本周 | 上周 | 月累计 |
|------|------|------|--------|
| 在招岗位 | 32 | 29 | 32 |
| 活跃候选人 | 187 | 163 | - |
| 面试人次 | 41 | 36 | 156 |
| Offer | 7 | 5 | 22 |
| 入职 | 4 | 3 | 15 |
| 渠道转化 Top3 | 内推/猎聘/官网 | - | - |

## 亮点
- 🌟 高端：N 型组件研发总监候选人 XX 已终面
- 🌟 校招：与浙大/华南理工达成校企合作意向
- 🌟 流程：研发 P7 平均周期压至 21 天

## 卡点 & 风险
- 🔴 工艺工程师：薪资带宽低于候选人期望 8k，需 HR 审批
- 🟡 校招：目标院校宣讲时间冲突，需协调

## 下周计划
- 发 Offer：4 份（含 1 份高端）
- 启动：海外人才地图
- 关闭：5 个长期未推岗位
```

## 推送
