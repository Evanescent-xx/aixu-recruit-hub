# Skill 02 — 简历评估

## 触发词
`/screen`

## 输入格式
```
/screen [JD编号] [简历文件/文本]
```

例：`/screen JD-2026-047 [粘贴简历全文]`

## 评估流程

1. **基本信息抽取**：姓名/学历/工作年限/最近 3 段经历/期望地/期望薪
2. **5 维打分**（总分 100）：
   - 行业匹配（30）：光储/电池/新能源/半导体 → 加分
   - 技术深度（25）：与 JD 硬技能逐条对齐
   - 业绩可验证（20）：量化成果（X% 提升 / X 亿营收 / X 人团队）
   - 稳定性（15）：履历连贯性、跳槽频次、理由合理性
   - 文化契合（10）：从经历侧写抗压/长期主义
3. **红线圈定**：造假、年龄与年限不符、价值观冲突 → 一票否决
4. **结论输出**：
   - ≥ 80：约面，并指派面试官
   - 60-79：进入备选池，每 30 天触达一次
   - < 60：拒，附 1 句友好话术

## 输出模板

```markdown
## 评估卡 — 候选人 XXX

**匹配度**：82 / 100  | **建议**：约面
**JD**：JD-2026-047 光伏组件研发总监

### 亮点
- 主导 XX 项目，效率提升 30%
- 10 年光伏行业经验，团队管理 50 人

### 风险
- 近 3 年跳槽 3 次，需追问稳定性
- 期望薪资高于 Band 上限 15%

### 推荐面试官
研发副总裁 + HRD（背靠背）

### 初轮问题
1. 你在 XX 项目中最关键的一个技术决策是什么？
2. 如何处理与海外团队的语言/时差协作？
3. 为什么离开上一家？最不能接受的下家是哪类？
```

## 反例
- 仅给分数不给依据 → 必须有亮点 + 风险
- 模糊话术"感觉还不错" → 不写主观感受，只写事实判断
