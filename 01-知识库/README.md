# 爱旭股份 Aiko Solar — 招聘知识库

> 用途：为所有招聘场景（社招/校招/高端/通用）提供统一的事实底座。  
> 谁来读：4 个数字员工（JD/筛选/面试官/周报）+ 招聘HR 真人。  
> 维护人：招聘组长 + TA Lead。每季度校准一次。

---

## 目录结构

```
01-知识库/
├─ 公司介绍/          # 业务、文化、战略、人才观
├─ 岗位画像/          # 按 4 大方向拆分的 JD 标准模板
│   ├─ 光储电池/      # 社招主营
│   ├─ 校招/
│   ├─ 高端人才/
│   └─ 通用职能/
├─ 面试标准/          # 各层级能力模型 + 评估要点
├─ 薪酬福利/          # Band 对标 + 激励结构
└─ FAQ/               # 候选人高频问题答疑口径
```

## 怎么用

1. **数字员工启动前** → 先用知识库做 RAG 检索，避免编造数字/岗位。
2. **新岗位** → 先到「岗位画像」找最相近模板，复制后再差异化。
3. **面试争议** → 回「面试标准」找对应层级的硬指标。
4. **薪酬谈判** → 回「薪酬福利」看 Band 表，避免拍脑袋。

> ⚠️ 任何写进对外材料（JD、邀约话术、面评、Offer）的具体数字，必须能从本知识库追溯。
