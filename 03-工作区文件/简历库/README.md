# 简历库

> 招聘过程沉淀下来的候选人简历。命名规范：`简历_候选人_年份_方向.md`

## 子目录
```
简历库/
├─ 在面/           # 当前正在面试流程
├─ 已通过/         # 已发 Offer / 入职
├─ 已淘汰/         # 不通过（保留 90 天后归档）
└─ 备选池/         # 暂未推进但有潜力（人才库激活对象）
```

## 每份简历文件包含
- 基本信息（脱敏后）
- 来源渠道
- 评估卡（来自数字员工 2 · 简历筛选官）
- 面试历史（如有）
- 当前状态

## 隐私
- 仅记录业务必需字段，手机/邮箱/身份证做脱敏
- 离职后 2 年可申请删除
