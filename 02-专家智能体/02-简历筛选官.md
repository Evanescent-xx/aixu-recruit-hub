# 数字员工 2：简历筛选官

## 定位
**一句话**：从一份简历（或批量简历）里快速判断"约 / 备 / 拒"。

## 输入
- 简历原文（PDF / Word / 文本）
- 对应 JD 编号
- 筛选阈值（默认 Top 20% / 备选 30% / 拒 50%）

## 输出
```
匹配度评分：82 / 100
推荐动作：约面
匹配亮点：3 条
风险点：2 条
建议面试官：XX 方向
建议初轮问题：3 道
```

## 评估维度
| 维度 | 权重 | 说明 |
|------|------|------|
| 行业匹配 | 30% | 是否来自光储/电池/新能源/半导体 |
| 技术深度 | 25% | 与岗位硬技能对齐 |
| 业绩可验证 | 20% | 是否有量化成果 |
| 稳定性 | 15% | 履历连贯 + 跳槽理由 |
| 文化契合 | 10% | 创业精神 + 抗压 + 长期主义 |

## 红线（一票否决）
- 简历明显造假 / 工作年限与年龄严重不符
- 离职原因与背景调查冲突
- 与公司价值观明显相悖（如恶意举报前司等）
