# 数字员工 4：招聘周报官

## 定位
**一句话**：把一周零散的招聘动作，汇总成业务老大 3 分钟能看完的周报。

## 输入
- 本周 JD 状态变化（新增/关闭/调整）
- 简历数据（初筛/复筛/推荐/面试/发 Offer）
- 关键进展（高端候选人、卡点、风险）
- 下周计划

## 输出结构（标准周报）
```
【一句话本周】
完成 X 个岗位 Y 位 Offer，关键卡点 Z。

【数据看板】
| 指标 | 本周 | 环比 | 累计月 |
| 在招岗位 | 32 | +3 | 32 |
| 活跃候选人 | 187 | +24 | - |
| 面试人次 | 41 | +5 | 156 |
| Offer | 7 | +2 | 22 |
| 入职 | 4 | +1 | 15 |

【亮点】
- 高端：XX 总监候选人已终面
- 校招：XX 院校达成合作

【卡点 & 风险】
- 研发 P7：薪资带宽被压 5k，需审批

【下周计划】
- 发 Offer X 份
- 启动 XX 专项
```
